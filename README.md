# NFLDraftingTool26

A NFL player valuation project that uses a custom-built algorithm to estimate player value and positional scarcity for the 2026–27 NFL season.
I built this to out-draft my football nerd friends.

The goal is to experiment with different ways of evaluating NFL players beyond simple rankings. The algorithm considers factors like player talent, positional value, and scarcity to produce a custom valuation for each player.

This is primarily a for-fun / learning project and isn't intended to be a definitive measure of player value.
